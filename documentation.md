## Introduction
Yournal is a privacy-focused Android application designed for seamless note-taking and voice recording with on-device transcription capabilities. It leverages modern Android development practices and local AI models to ensure user data remains private and accessible.

## Core Architecture
The Yournal app is built on a robust **MVVM (Model-View-ViewModel)** architecture, utilizing Android's latest components for lifecycle management and data persistence.

### 1. Audio Engine
The audio recording system in Yournal is designed for high performance and reliability. It avoids the latency issues of the standard `MediaRecorder` by using a custom dual-thread architecture.

- **Audio Capture**: Captures raw PCM data using `AudioRecord` at a sample rate optimized for the hardware (typically 44.1kHz or 48kHz).
- **Dual-Thread Processing**:
    - **CaptureThread**: Continuously pulls bytes from the `AudioRecord` hardware buffer and offers them to a `LinkedBlockingQueue`.
    - **ProcessingThread**: Drains the queue and performs two simultaneous operations:
        - **Encoding**: Uses `MediaCodec` (AAC) to compress the raw audio into an `.m4a` file via `MediaMuxer`.
        - **Live Analysis**: Calculates real-time amplitude for the waveform visualization and resamples audio for the transcription engine.
- **Waveform Visualization**: Real-time amplitude data is normalized and passed to the `WaveformView` to create a live-updating visual representation of the recording.

### 2. Transcription Engine (Vosk)
Yournal features fully offline, on-device transcription powered by the **Vosk STT engine**.

- **Model Management**: The app ships with the Vosk model folder `vosk-model-en-us-0.22-lgraph` in assets. On first run, `TranscriptionManager` extracts this model to internal storage for persistent access.
- **Real-Time Transcription**: During recording, the `AudioRecorderManager` feeds resampled 16kHz audio chunks into the Vosk `Recognizer`. 
    - **Partial Results**: Provides immediate feedback in the UI as the user speaks.
    - **Final Results**: Once a pause is detected, the full sentence is finalized and appended to the transcription buffer.
- **Background Support**: For existing recordings, `TranscriptionService` can perform batch transcription in the background, allowing the user to navigate away while processing continues.

### 3. Data Layer & Room
Yournal uses **Room Persistence Library** with RxJava3 integration for a reactive, thread-safe data layer.

#### YournalEntry Entity
The core data structure is the `YournalEntry` class:
- `id`: Auto-generated primary key.
- `noteTitle`: User-defined or auto-generated title.
- `filePath`: URI/Path to the stored `.m4a` audio file.
- `noteType`: Categorizes entry (e.g., "recording", "text").
- `noteContent`: The transcribed text or manual note content.
- `dateCreated`/`dateDeleted`: Unix timestamps for chronological sorting and recycle bin management.
- `amplitudes`: A `List<Float>` of sampled amplitudes stored via a TypeConverter, allowing the `WaveformView` to reconstruct the waveform during playback without re-analyzing the audio file.
- `tags`: A list of strings for organization.

### 4. UI Architecture
- **Navigation Component**: Manages transitions between `HomeFragment`, `RecorderFragment`, and `SettingsFragment`.
- **ViewBinding**: Ensures type-safe access to XML layout elements.
- **Fragments & Services**: `RecorderFragment` binds to `RecordingService` via a `LocalBinder`. This allows the recording logic to outlive the UI fragment, preventing data loss if the screen rotates or the user briefly switches apps.

## Setup and Installation
1.  Clone the repository.
2.  Open the project in Android Studio (Ladybug or newer recommended).
3.  Sync Gradle dependencies.
4.  Run the application on a device with API level 26 or higher.

## Key Class Responsibilities
- `AudioRecorderManager`: Manages the low-level capture, encoding, and Vosk feeding.
- `TranscriptionManager`: Handles Vosk model initialization and file-to-text batch processing.
- `RecordingService`: Acts as a persistent wrapper around the recorder and player, providing foreground service notifications.
- `RecorderFragment`: The UI controller for capturing audio, viewing waveforms, and seeing live transcripts.
- `YournalRepository`: The single point of truth for data operations.
